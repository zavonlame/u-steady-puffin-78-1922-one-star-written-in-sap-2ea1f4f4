## How it works

`main.ts` (Node 22, stdlib only) composes the review from three beats —
rating, grievance, punchline — checks it against the gate (1–279 chars,
single line, non-blank), and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no files read, no Chrome.
